# Turtle Racing Game

A fun Turtle Graphics racing game built with Python where players place a bet on a turtle's color and watch the race unfold. Each turtle moves a random distance during every turn, making the outcome unpredictable and exciting.

## Features

- Six colorful racing turtles
- User betting system
- Randomized race movement
- Winner detection
- Win/Lose result announcement
- Interactive graphical interface using Turtle Graphics

## Technologies Used

- Python 3
- Turtle Graphics
- Random Module

## How to Run

1. Clone the repository:

```bash
git clone <your-repository-url>
```

2. Navigate to the project folder:

```bash
cd turtle-racing-game
```

3. Run the program:

```bash
python main.py
```

## How to Play

1. Enter a turtle color when prompted.
2. Watch the race begin.
3. Each turtle moves forward by a random distance.
4. The first turtle to cross the finish line wins.
5. The program tells you whether your prediction was correct.
