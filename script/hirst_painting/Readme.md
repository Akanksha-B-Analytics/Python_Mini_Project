# Hirst Dot Painting Generator

A Python Turtle Graphics project that recreates a Damien Hirst-inspired dot painting. The program generates a 10×10 grid of colored dots using randomly selected colors from a predefined palette.

## Features

- Generates a colorful dot painting automatically
- Uses Python Turtle Graphics for visualization
- Random color selection for each dot
- Modular design using functions
- Demonstrates loops, functions, and coordinate manipulation

## How It Works

1. The turtle moves to a starting position.
2. A row of colored dots is drawn.
3. The turtle repositions itself to the next row.
4. The process repeats until a complete 10×10 grid is created.
5. The generated artwork remains visible until the user closes the window.

## Concepts Demonstrated

- Python Turtle Graphics
- Functions
- Loops
- Random Module
- Coordinate System Navigation
- Modular Programming

## How to Run

```bash
python main.py
```
