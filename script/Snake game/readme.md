
# Snake Game

A classic Snake Game built with Python using the Turtle Graphics library. Control the snake, collect food to grow longer, increase your score, and avoid colliding with walls or your own tail.

## Features

- Smooth snake movement
- Arrow key controls
- Random food spawning
- Dynamic snake growth
- Real-time score tracking
- Wall collision detection
- Tail collision detection
- Game Over screen

## Project Structure

```text
snake_game/
│
├── main.py          # Main game controller
├── snake.py         # Snake class and movement logic
├── food.py          # Food generation and positioning
├── scoreboard.py    # Score tracking and game-over display
└── README.md
```

## Technologies Used

- Python 3
- Turtle Graphics
- Object-Oriented Programming (OOP)

## How to Run

1. Clone the repository:

```bash
git clone <your-repository-url>
```

2. Navigate to the project folder:

```bash
cd snake_game
```

3. Run the game:

```bash
python main.py
```

## Controls

| Key | Action |
|------|----------|
| ↑ | Move Up |
| ↓ | Move Down |
| ← | Move Left |
| → | Move Right |

## Game Rules

1. Use the arrow keys to control the snake.
2. Eat food to grow longer and increase your score.
3. Avoid hitting the walls.
4. Avoid colliding with your own tail.
5. The game ends when a collision occurs.
